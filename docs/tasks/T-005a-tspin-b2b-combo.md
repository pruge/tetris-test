# T-005a — T-스핀, 백투백, 콤보

Phase: 3 · Status: Ready · Depends on: T-004 (`742542a`)

## Summary

점수 규칙을 완성한다. T-스핀을 판정해 보너스를 주고, 어려운 클리어가
연속되면 백투백(B2B) 1.5배, 조각이 연속으로 줄을 지우면 콤보 보너스를
준다. 지금은 줄 수만 보고 점수를 준다.

## 병렬 작업 주의

**T-005b 가 같은 파일을 동시에 수정 중이다.**

- 너는 LOGIC 의 회전 판정과 `applyLineClears` 주변, `lockAndSpawn` 을 소유한다.
- **INPUT 섹션, RENDER 섹션, `ui` 객체, `resetGame()` 을 건드리지 마라.**
  T-005b 의 영역이다.
- `state` 에 추가할 필드는 **`level:` 줄 바로 다음**에 넣어라.
  객체 끝(`canHold` 이후)은 T-005b 의 영역이다.
- 점수를 화면에 표시하는 코드를 만들지 마라. `state` 에 값만 유지한다.
  T-005b 가 `state.score` 를 읽어 최고 점수를 저장한다 — **읽기 전용
  의존이므로 네가 값을 어떻게 만들든 상관없다.**

## 기존 코드에서 반드시 지킬 것

- `tryRotate(board, piece, dir)` 는 성공한 piece 또는 `null` 을 반환한다.
  T-스핀 판정에 킥 정보가 필요하면 **시그니처를 바꾸지 말고** 판정을
  별도 순수 함수로 분리해라: `isTSpin(board, piece, usedKickIndex)` 같은 형태.
  호출부에서 필요한 정보를 넘긴다.
- 점수 계산은 순수 함수로 유지한다. 기존 `lineClearScore(clearedCount, level)`
  옆에 새 함수를 두고, `applyLineClears` 가 조합한다.
- 3-corner 룰로 판정한다: T 조각의 회전 중심 기준 네 모서리 중 **3개 이상이
  막혀 있으면** T-스핀. 막힘은 벽·바닥·기존 블록 전부 포함한다.
  계획 문서 Decision point 3 의 확정 사항이다.
- 새 상수(T-스핀 점수표, B2B 배수, 콤보 점수)는 전부 `CONFIG` 에.
- `collides`, `lockPiece`, `pieceCells`, `clearLines`, `rotated` 를 건드리지 마라.

## 명세

**T-스핀 판정.** 마지막 동작이 **회전**이었고, 조각이 T 이고, 3-corner
조건을 만족하면 T-스핀이다. 이동이나 낙하로 자리를 잡았다면 T-스핀이 아니다.

**T-스핀 점수** (`CONFIG.TSPIN_SCORES`, × 레벨):
0줄 400 / 1줄 800 / 2줄 1200 / 3줄 1600.
일반 클리어 점수(`LINE_SCORES`) 대신 이 값을 쓴다.

**B2B.** "어려운 클리어" = 4줄 클리어(테트리스) 또는 T-스핀 클리어(0줄 제외).
어려운 클리어가 연속되면 두 번째부터 점수 × `CONFIG.B2B_MULTIPLIER`(=1.5).
어려운 클리어가 아닌 **줄 클리어**가 나오면 연쇄가 끊긴다. 줄을 지우지 않은
고정은 연쇄를 끊지 않는다.

**콤보.** 조각이 연속으로 줄을 지운 횟수. 첫 클리어가 콤보 0, 다음이 1.
보너스 = `CONFIG.COMBO_POINTS`(=50) × 콤보 수 × 레벨. 줄을 못 지우면 0으로
초기화된다.

## Acceptance criteria

1. 새 점수 함수들이 순수 함수다. 인자를 변형하지 않고 같은 입력에 같은 값을
   반환한다.
2. 3-corner 조건을 만족하는 T 조각을 회전으로 끼워넣고 고정하면 T-스핀으로
   판정된다. 사용한 보드 배치를 적는다.
3. 같은 배치에서 **이동으로** 자리를 잡고 고정하면 T-스핀이 아니다.
4. T-스핀 싱글(1줄)이 레벨 1에서 800점이다. 일반 싱글 100점과 다름을 보인다.
5. 4줄 클리어를 연속 2회 하면 두 번째가 `800 × 1.5 = 1200` 점이다.
6. 4줄 → 1줄 → 4줄 순서에서 세 번째가 B2B 보너스를 받지 **않는다**
   (1줄이 연쇄를 끊는다).
7. 4줄 → 줄 없이 고정 → 4줄 순서에서 세 번째가 B2B 보너스를 받는다
   (줄 없는 고정은 끊지 않는다).
8. 3연속 클리어 시 콤보 보너스가 `50 × 0`, `50 × 1`, `50 × 2` (× 레벨)로
   누적된다. 줄을 못 지우면 콤보가 0으로 돌아간다.
9. `tryRotate`, `collides`, `lockPiece`, `pieceCells`, `clearLines`,
   `rotated` 의 시그니처가 변경되지 않았다 (`git diff` 로 보고).
10. INPUT 섹션, RENDER 섹션, `ui`, `resetGame` 이 변경되지 않았다
    (`git diff` 로 보고).
11. T-003b 기준 3, 9 가 여전히 성립한다 (일반 4줄 800점, 10줄에 레벨업).
