## 태스크 문서 규칙

각 태스크는 다음 섹션을 가진다. 순서를 지킨다.

1. **Summary** — 코드베이스를 모르는 사람 기준 2~3문장. "무엇을 만들면 끝인가".
2. **Scope** — 포함/제외를 명시적으로. 제외 항목에는 어느 태스크로 가는지 적는다.
3. **Acceptance criteria** — 번호를 매기고, 각 항목이 **검증 가능**해야 한다.
   "잘 동작한다" 는 기준이 아니다. "1초에 한 칸 내려간다" 가 기준이다.
4. **Out of scope / 하지 말 것** — 에이전트가 넘치게 일하는 것을 막는 울타리.
5. **Verification** — 어떻게 확인하고 무엇을 보고할지.

한 태스크는 한 스레드가 한 번에 끝낼 수 있는 크기여야 한다. 수용 기준이
10개를 넘으면 태스크를 쪼갠다.
